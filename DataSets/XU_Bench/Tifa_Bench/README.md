## task: generate id_map and caption_map
给定一个文件/home/sxm/flux-workspace/Qwen-Image-Lightning/DataSets/XU_Bench/Tifa_Bench/tifa_v1.0/tifa_v1.0_text_inputs.json
其格式如下：
[
    {
        "id": "coco_301091",
        "caption": "On a gray day a surfer carrying a white board walks on a beach.",
        "coco_val_id": "380711"
    },
    {
        "id": "coco_421933",
        "caption": "A person sitting on a horse in air over gate in grass with people and trees in background.",
        "coco_val_id": "260106"
    },

提取其中的id和caption，分别构建{id：caption}和{caption：id}的map，并将这两个map以json的格式保存在两个json文件夹中

## task: combine tifaData.p and coco_prompt_layout.p
tifaData.p和coco_prompt_layout.p的格式如下：
{'prompt': 'a real scene of desert road with a sign written on it "a bicycle and toaster make a strange combination."', '0': {'description': 'desert road', 'mask': [0, 0, 512, 384]}, '1': {'description': 'sign', 'mask': [180, 384, 332, 460]}, '2': {'description': '"a bicycle and toaster make a strange combination."', 'mask': [190, 410, 322, 450]}, '3': {'description': 'bicycle', 'mask': [50, 300, 150, 384]}, '4': {'description': 'toaster', 'mask': [362, 320, 462, 384]}}
读取/home/sxm/flux-workspace/Qwen-Image-Lightning/DataSets/XU_Bench/Tifa_Bench/tifa_v1.0/caption_to_id.json文件构建map,基于
prompt能够获取到对应的id,现在需要以coco_prompt_layout.p中的数据为准，将tifaData.p中有但是coco_prompt_layout.p中没有的数据合并到
coco_prompt_layout.p中,并保存成一个新的文件，叫做qwen_coco_combined.p

``` bash
python combine_coco_qwen.py
```
